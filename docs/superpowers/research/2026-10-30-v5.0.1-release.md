## Installed Windows verification

- Verified protected backups of settings, grants, schema, encrypted vault files, and previous program code before the signed service update. A separate user-side backup retains the previous global CLI, dependencies, and launchers.
- The installed global CLI matches all 85 public package files byte-for-byte.
- The signed updater restarted the service before its initiating IPC response completed. The CLI reported a closed connection; installation was checked independently rather than treating that response as update proof.
- The running service reports `5.0.1`. A privileged comparison confirms all 85 installed service package files match the verified artifact.
- Settings and grants remain byte-identical to the pre-update backup. One vault data file changed; removing only `global_config_byServer` makes the parsed before/after content equal. No other stored vault fields changed. No credentials, session keys, or raw protected data were printed.
- `setup --apply --json` reports `configured`, Edge selected, matching ready client configuration, and no required configuration restart. Its shell action moved the regenerated npm PowerShell launcher into the user's `#0 backup`.
- A fresh PowerShell process with `-NoProfile -ExecutionPolicy Restricted` resolves `u-chan` to `u-chan.cmd` and runs `u-chan doctor --json`. All required checks pass, including installed versions, assets, protected permissions, and Edge owner/profile identity. Active AI-session Playwright ownership remains advisory/unknown.
- After the user unlocked the restarted service through its protected prompt, a fresh MCP process advertised `u-chan-secrets` version `5.0.1` and exactly five tools. Login to an existing approved site returned `logged in`, exercising approved success evidence in both the private context and transferred Edge session.

Restart existing AI sessions after upgrading the package so their long-running MCP processes load the new version, even if setup did not change the registration. Site-specific success conditions remain local protected approvals and are not distributed with this release.

The changed owner-path logic was exercised by the actual SYSTEM-owned Windows service. Native helper bytes and dependencies remain unchanged from 5.0.0; this patch did not rerun the entire disposable adversarial matrix. macOS CI passed, but native macOS runtime remains unverified.
